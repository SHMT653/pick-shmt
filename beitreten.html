Raum beitreten

Gib den 6-stelligen Code ein, den du von der Gruppe bekommen hast.

So funktioniert's
  1. Code eingebenDen 6-stelligen Code von deiner Gruppe eintragen.
  2. Name wählenSo erkennen dich die anderen im Raum.
  3. Gemeinsam entscheidenAlle stimmen ab, Pickr liefert das Ergebnis.
