Raum erstellen

Lege einen neuen Entscheidungsraum an und teile den Code gleich mit deiner Gruppe.

So funktioniert's
  1. Raum erstellenFrage festlegen und deinen Namen eingeben.
  2. Code teilenLink oder QR-Code an deine Gruppe schicken.
  3. Gemeinsam entscheidenAlle stimmen ab, Pickr liefert das Ergebnis.
